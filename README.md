# RecetasApp

## Descripción

Aplicación móvil para reunir y consultar las recetas de cocina
en un solo lugar: nombre, categoría, dificultad, tiempo de 
preparación, porciones, ingredientes y pasos.

## Integrantes

- Castro Santiago
- Cano Nazareno
- Cordoba Milagros
- Insegna Belen
- Zambrano Facundo
